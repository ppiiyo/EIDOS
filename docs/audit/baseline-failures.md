# Baseline Test Audit Without CI Injects (`P0-1`)

## 1. Context

Prior to `P0-1`, the repository contained 25 Python mutation scripts (`scripts/inject_*.py`), `scripts/apply_master_p0.py`, `scripts/apply_p0_104_105_remaining.py`, `scripts/apply_vector_store_p0.sh`, and `scripts/verify_injects.sh`, along with GitHub Actions workflows (`.github/workflows/auto-apply-p0.yml`, `.github/workflows/apply-p0.yml`, `.github/workflows/verify-injects-daily.yml`).

While the product-side fixes from those scripts had already been committed to `apps/` and `packages/`, 9 of the scripts had ALSO mutated test files to weaken assertions or bypass the public HTTP API via internal `app.storeRegistry.getOrCreateStore(...).loadDemoCatalog(...)` calls.

## 2. Root Causes Identified & Resolved in Product / Test Setup
