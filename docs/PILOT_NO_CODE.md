# Запуск пилота EIDOS без программиста (No-Code Pilot Guide)

Эта памятка на 1 страницу предназначена для владельца интернет-магазина, e-commerce менеджера или системного администратора хостинга. Весь путь от чистой VPS до живого поиска на сайте занимает **15–20 минут**.

---

## 1. Требования к серверу (VPS)

Для каталога до **50 000 товаров** достаточно стандартного облачного сервера:
- **CPU:** 2 vCPU
- **RAM:** 2 ГБ ОЗУ (минимум) / 4 ГБ ОЗУ (рекомендуется)
- **Диск:** 10 ГБ SSD (для Docker-образов и векторных снэпшотов)
- **ОС:** Ubuntu 22.04 / 24.04 или Debian 12 с установленным Docker (`docker compose`)

---

## 2. Шаг 1 — Запуск сервиса одной командой (2 минуты)

Подключитесь к серверу по SSH и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/ppiiyo/EIDOS/main/scripts/install-pilot.sh | bash
```

*(Либо в склонированном репозитории: `./scripts/install-pilot.sh`)*

**Что сделает скрипт автоматически:**
1. Проверит наличие Docker и `docker compose`.
2. Создаст рабочую папку `eidos-pilot/` и сгенерирует три криптостойких ключа (`>= 32` символов) в файле `.env`:
   - `EIDOS_MASTER_KEY` — главный ключ безопасности
   - `EIDOS_ADMIN_KEY` — ключ для загрузки товаров в мастере настройки
   - `EIDOS_SEARCH_KEY` — публичный read-only ключ для виджета на сайте
3. Запустит контейнеры `eidos-api` и `redis`, дождётся готовности индекса (`GET /v1/ready == 200`) и выведет на экран ссылку на мастер настройки.

---

## 3. Шаг 2 — Загрузка каталога и автопроверка через браузер (5 минут)

1. Откройте ссылку из терминала: **`http://<IP-вашего-сервера>:3000/onboarding`** (или нажмите **«Мастер подключения»** в левом меню Studio UI).
2. **Ключи доступа (Шаг 1 мастера):** Вставьте `EIDOS_ADMIN_KEY` и `EIDOS_SEARCH_KEY`, которые скрипт вывел в консоль (они лежат в `eidos-pilot/.env`).
3. **Загрузка товаров (Шаг 2 мастера):**
   - Перетащите ваш прайс-лист в формате **CSV** или **JSON** в окно браузера (обязательные колонки: `id`, `title`, `category`, `price`; подробнее в [docs/CSV_CONTRACT.md](./CSV_CONTRACT.md)).
   - Если в какой-то строке пропущено название или некорректная цена, мастер сразу покажет номер строки и поле.
   - Нажмите **«Индексировать в EIDOS»** — вы увидите прогресс-бар и итоговый статус: **`N товаров в индексе`**.
4. **Автоматический тест качества (Шаг 3 мастера):**
   - Нажмите **«Запустить 5 проверочных запросов»**.
   - Система автоматически проверит точный поиск по названиям ваших товаров, поиск по бренду/артикулу, смысловой (гибридный) запрос и защиту от мусорной выдачи на несуществующем слове.

---

## 4. Шаг 3 — Вставка виджета на сайт (5 минут)

На **Шаге 4 мастера `/onboarding`** скопируйте готовый HTML-код с уже подставленным `EIDOS_SEARCH_KEY` и вставьте его перед `</body>` в шаблоне вашего сайта (Tilda, 1C-Bitrix, WooCommerce, OpenCart, InSales или самописный сайт):

```html
<script
  src="http://<IP-или-домен-поиска>:3000/widget.js"
  defer
  data-api="http://<IP-или-домен-поиска>:3000"
  data-key="eidos_sk_ВАШ_SEARCH_KEY"
  data-input="#title-search-input, input[name='q'], .search-input"
  data-limit="8"
  data-product-url-template="/catalog/#ID#/"
></script>
```

> Подробная инструкция для **1C-Bitrix** (включая `header.php`, шаблон ссылок `/catalog/#ID#/` и выгрузку из Инфоблока): [docs/integrations/bitrix-widget.md](./integrations/bitrix-widget.md).

## 5. Если что-то пошло не так (Быстрая диагностика)

| Симптом | Причина и решение |
| :--- | :--- |
| **Поиск на витрине возвращает 0 товаров на любые слова** | В индекс ещё не загружен каталог (`0 SKU`). Откройте `/onboarding` → Шаг 2 и загрузите CSV-файл с вашим `EIDOS_ADMIN_KEY`. |
| **В консоли браузера ошибка CORS при вводе в строку поиска** | Откройте `eidos-pilot/.env`, укажите домен вашего магазина в `CORS_ORIGIN=https://ваш-магазин.рф` и перезапустите: `docker compose -f docker-compose.pilot.yml up -d`. |
| **Виджет пишет `Refusing to initialize with MASTER or ADMIN key`** | В атрибут `data-key` на сайте случайно вставили `EIDOS_ADMIN_KEY` (`eidos_ak_...`). Замените его на безопасный `EIDOS_SEARCH_KEY` (`eidos_sk_...`). |
| **Клик по товару в виджете ведёт на неправильный адрес** | Добавьте колонку `url` в ваш CSV-файл или настройте шаблон `data-product-url-template="/catalog/#ID#/"` в теге `<script>`. |
